# backstab

Game-theoretic analysis and Monte Carlo simulation of The Traitors.

To install the library:

```
$ uv add backstab
```

Documentation is available at: [https://vknight.org/backstab/](https://vknight.org/backstab/).

This library was used for the preprint [The Vote-Left Equilibrium: A Deterministic Coordination Strategy for the Faithful in The Traitors](https://arxiv.org/abs/2605.10233).
